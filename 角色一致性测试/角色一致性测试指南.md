# 角色一致性对比测试指南

## 📋 测试概述

本测试通过**实际生成视频**来验证角色一致性机制的效果。

### 测试原理
- **A组（实验组）**：使用角色一致性机制生成视频
- **B组（对照组）**：不使用角色一致性机制生成视频
- **对比**：人工评估两组视频中同一角色的外观一致性

### 测试场景
测试角色"苏清雨"在5个不同场景中的表现：
1. ☕ 咖啡店工作（工作装）
2. 🏃 公园慢跑（运动装）
3. 📚 家中阅读（家居服）
4. 🧘 健身房瑜伽（瑜伽服）
5. 🍷 晚宴聚会（晚礼服）

## 🚀 执行测试

### 方法一：运行完整对比测试（推荐）

```bash
python run_consistency_comparison.py
```

**测试流程：**
1. 加载测试分镜脚本
2. A组：生成5个视频（带角色一致性）
3. B组：生成5个视频（不带角色一致性）
4. 生成对比报告

**预计时间：** 约30-50分钟（取决于API响应速度）

### 方法二：使用专业工作流手动测试

```bash
python kling_professional_workflow.py
```

然后按提示：
1. 输入分镜文件：`test_consistency_storyboard.json`
2. 确认角色形象
3. 启用角色一致性
4. 生成视频

## 📊 评估标准

下载生成的视频后，按以下标准评估：

### 1. 面部特征一致性 ⭐⭐⭐⭐⭐
- [ ] 脸型是否保持一致
- [ ] 五官（眼睛、鼻子、嘴唇）是否相似
- [ ] 肤色是否统一

### 2. 发型发色一致性 ⭐⭐⭐⭐⭐
- [ ] 发色是否都是黑色
- [ ] 发型是否都是长发
- [ ] 头发质感是否相似

### 3. 身材体型一致性 ⭐⭐⭐⭐
- [ ] 身材是否都是苗条
- [ ] 身高比例是否一致
- [ ] 体态是否优雅

### 4. 种族特征稳定性 ⭐⭐⭐⭐⭐
- [ ] 是否都是东亚女性面孔
- [ ] 种族特征是否明显且一致

### 5. 服装变化合理性 ⭐⭐⭐
- [ ] 服装是否随场景合理变化
- [ ] 服装风格是否符合场景设定

### 6. 表情自然度 ⭐⭐⭐
- [ ] 表情是否符合场景情绪
- [ ] 表情变化是否自然

## 💡 注意事项

1. **API费用**：测试会生成10个视频，注意API使用额度
2. **等待时间**：每个视频生成需要3-5分钟
3. **网络稳定**：确保测试过程中网络稳定
4. **及时下载**：视频URL有时效性，生成后及时下载

## 🔧 故障排除

### 问题1：API Key无效
**解决：** 确保设置了环境变量 `DASHSCOPE_API_KEY`

### 问题2：任务创建失败
**解决：** 检查API配额是否充足，稍后重试

### 问题3：视频生成超时
**解决：** 增加超时时间或检查网络连接

### 问题4：视频URL无法访问
**解决：** URL可能已过期，需要重新生成
