# script-tool-v6 新功能说明

v6 在 v5 基础上新增/调整三块能力（**v5 未做任何改动**）：

- **A. 画面时间戳定向编辑（时间轴 beats）** —— 把单个镜头拆成「0-5秒 / 5-10秒…」分段描述
- **B. 角色配音（CosyVoice 语音合成 + 音画混流）** —— 给每个角色配音色/情绪/语速/音调/音量，视频自动混入配音
- **C. 影视化工作台 ↔ Prompt 中心去重** —— 消除两处重复编辑分镜导致的数据互相覆盖

A、B 都落在 **Prompt 中心**（`/projects/{id}/prompts`）。

---

## 一、画面时间轴（时间戳定向编辑）

**位置**：Prompt 中心 → 每个镜头卡片 → 「🎬 画面时间轴」区。

**做什么**：把一个镜头按时间拆成若干段，每段填「起始秒→结束秒 + 画面动作 + 运镜（可选台词）」。
填了分段后，该镜头的**视频 Prompt 会自动变成时序式**：

```
中景。0-5秒：走进教室（跟拍）；5-10秒：坐下（特写），说：「终于到了」。画面中不得出现任何文字…
```

**按钮**：
- `▸ 分段编辑`：展开/收起分段列表
- `⚡ 按时长均分`：按镜头时长快速起稿若干空段
- `＋ 添加一段` / 每段末尾 `✕`：增删分段

**适配模型**：这种时序 prompt 对**支持时序/多镜头描述的模型效果最佳**（如 Seedance 2.5、wan3.0 多镜头）；对不支持的模型，也会被当作更结构化的分段描述。将来接入任何支持时序的模型都可直接复用，无需返工。

**数据结构**：`shot.beats = [{start, end, action, camera, dialogue}]`；保存镜头时后端 `normalize_beats` 会规整（排序、时间交换、夹取到镜头时长），并用它重算 `video_prompt`。

## 二、角色配音（CosyVoice）

### 使用流程

1. **配角色声音**：Prompt 中心 →「🎙 角色配音」→ 为每个角色选 **音色 / 情绪 / 语速 / 音调 / 音量** → `▶ 试听` → `💾 保存`
2. **配台词**：镜头卡片的「💬 字幕」里，每句 `cue` 的**说话人**填对应角色名（配音会按说话人取该角色的声音）
3. **生成配音**：镜头卡片 →「🔊 生成配音」（会先保存字幕，再逐句合成音频）
4. **出片混流**：在项目页生成视频时，若该镜头已有配音，视频下载后会**自动按时间轴混入配音**（`shot_N_voiced.mp4`）

### 专业配音参数（映射 CosyVoice）

| 选项 | 说明 | CosyVoice 参数 | 范围 |
|------|------|---------------|------|
| 音色 | 角色声线（性别/年龄/气质） | `voice` | 46 个系统音色，分类可选 |
| 情绪 | 情感色彩 | `instruction` | 平静/高兴/悲伤/愤怒/恐惧/惊讶/厌恶 |
| 语速 | 快慢 | `speech_rate` | 0.5–2.0 |
| 音调 | 高低（声调） | `pitch_rate` | 0.5–2.0 |
| 音量 | 大小 | `volume` | 0–100 |

> 单句覆盖：字幕 `cue.voice` 可覆盖该句的情绪等（同一角色不同台词可有不同情绪）。

### 音色库与「情绪」的重要约束

- 音色库共 **46 个系统音色**，按 男主/男配/女主/女配/老年/童声/旁白/方言/外语 分类。
- 下拉里带 **`♥情感`** 标记的音色（如 `longanyang` 龙安洋、`longanhuan` 龙安欢、`longhuhu_v3` 龙呼呼）**才支持情绪指令**；这是 CosyVoice 官方限制（情感值固定 7 种，指令格式严格）。
- 选了**不支持情绪**的音色时，情绪会自动降级——由**语速/音调/音量**近似表达，不会报错。

### 前提与约束（务必阅读）

1. **依赖 dashscope SDK**：`requirements.txt` 已加 `dashscope>=1.26.4`，需 `pip install`。
2. **复用现有 Key**：配音走 `SCRIPT_TOOL_DASHSCOPE_API_KEY`，但该 Key 需在**百炼控制台开通「语音合成」服务**。
3. **云端付费**：CosyVoice 是按字符计费的云服务（非本地免费）。
4. **⚠️ 口型不同步**：现有视频模型输出的是**无声视频**，配音是**后期混入**，因此画面里人物的**嘴型不会跟随配音**。若需口型同步，需另接专门的口型驱动（如 Wav2Lip/SadTalker）或换用原生音画同生的模型（如 Seedance 2.5）——v6 未包含。
5. CosyVoice **v1 已下线**，默认用 `cosyvoice-v3-flash`。

### 相关配置（`.env`）

```
SCRIPT_TOOL_COSYVOICE_MODEL=cosyvoice-v3-flash   # 语音合成模型
SCRIPT_TOOL_COSYVOICE_VOICE=longanyang           # 默认音色
SCRIPT_TOOL_COSYVOICE_VOLUME=50                  # 默认音量 0-100
SCRIPT_TOOL_COSYVOICE_RATE=1.0                   # 默认语速 0.5-2.0
SCRIPT_TOOL_COSYVOICE_PITCH=1.0                  # 默认音调 0.5-2.0
SCRIPT_TOOL_COSYVOICE_FORMAT=mp3                 # 音频格式 mp3/wav/pcm
SCRIPT_TOOL_VOICE_MUX=1                          # 视频是否默认混入配音（0=关闭）
# 用业务空间专属域名时才需填：
# SCRIPT_TOOL_COSYVOICE_WS_URL=wss://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference
```

## 三、影视化工作台 ↔ Prompt 中心去重

**原问题**：项目页「③ 影视化工作台」的分镜表和独立的「🎯 Prompt 中心」都能编辑分镜，且两者都写 `video_prompt`——影视化弹窗直接改文本，Prompt 中心改结构化要素后会重算覆盖，**互相打架**。

**v6 方案（温和去重，职责分离）**：

| 模块 | 职责 |
|------|------|
| **Prompt 中心** | 分镜的**编辑权威**：结构化要素、画面时间轴、字幕、**配音**、确认、拆分、导出 |
| **影视化工作台** | **出片执行**：生成分镜、只读概览表、勾选生成视频、首帧上传 |

具体改动：影视化分镜表**移除**了「导出 JSON/Markdown」「保存全部」按钮和行内「✏️ 查看/编辑」弹窗入口，改为「🎯 去 Prompt 中心编辑」跳转；表格保留为只读概览 + 勾选 + 首帧 + 生成视频。

> 注：原 `modal-shot` 弹窗及 `openShotModal/saveShot/exportStoryboard/saveStoryboard` 等函数保留为**不再触发的兼容代码**，未删除以降低回归风险。
